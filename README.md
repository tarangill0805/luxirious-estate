# EstateX Real Estate Website

## Features
- Full-stack Flask + SQLite website
- Your uploaded drone video on the homepage
- Add inventory from /admin
- Upload property images
- Sell and rent filters
- Land, House, Kothi, Villa and more
- SEO basics: title/meta description, robots.txt, sitemap.xml
- Responsive design

## Run on Windows
1. Open terminal in this folder
2. `python -m venv venv`
3. `venv\Scripts\activate`
4. `pip install -r requirements.txt`
5. `python app.py`
6. Open `http://127.0.0.1:5000`

## Important
Before production, add authentication to /admin and change the Flask secret key.
